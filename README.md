# الموقع الشخصي لعمران سميح نزال

موقع شخصي احترافي لكاتب وباحث ومبدع محتوى، مبني بأحدث تقنيات الويب.

## التقنيات المستخدمة

- **Next.js 14** - إطار عمل React
- **TypeScript** - لغة TypeScript
- **Tailwind CSS** - تصميم CSS
- **Prisma** - ORM لقاعدة البيانات
- **SQLite** - قاعدة البيانات (قابلة التحويل إلى PostgreSQL)
- **JWT** - المصادقة
- **Framer Motion** - الحركات والتأثيرات

## الميزات

- الصفحة الرئيسية مع قسم بطل وعن الكتب والأبحاث
- صفحة الكتب مع البحث والتصنيف
- صفحة الأبحاث والمقالات
- صفحة التواصل مع نموذج رسائل
- لوحة تحكم إدارية كاملة (CMS)
- تصميم متجاوب بالكامل (RTL عربي)
- تحسين محركات البحث (SEO)
- رفع الملفات والصور

## التثبيت والتشغيل

### 1. تثبيت التبعيات

```bash
npm install
```

### 2. إعداد قاعدة البيانات

```bash
npx prisma db push
npx prisma generate
```

### 3. زراعة البيانات初始

```bash
npx tsx prisma/seed.ts
```

### 4. تشغيل المشروع

```bash
npm run dev
```

سيكون الموقع متاحاً على: `http://localhost:3000`

## بيانات تسجيل الدخول للوحة التحكم

- **اسم المستخدم:** `admin`
- **كلمة المرور:** `admin123`

> **مهم:** غيّر كلمة المرور في الإنتاج!

## صفحة الكتب

كل كتاب يحتوي على:
- صورة الغلاف
- العنوان والوصف
- اسم الكاتب
- تاريخ النشر
- التصنيف
- تحميل PDF (اختياري)
- رابط الشراء (اختياري)

## صفحة الأبحاث والمقالات

كل بحث يحتوي على:
- العنوان والملخص
- المحتوى الكامل
- التصنيف
- تاريخ النشر
- صورة الغلاف
- مرفق PDF
- قسم المراجع

## لوحة التحكم

### الميزات:
- تسجيل دخول آمن بتشفير كلمة المرور
- إدارة الكتب (إضافة/تعديل/حذف)
- إدارة الأبحاث (إضافة/تعديل/حذف)
- إدارة المقالات (إضافة/تعديل/حذف)
- رفع الصور والملفات
- عرض رسائل التواصل
